## Homework 2 - Data Science

**File:** `data.ipynb`

### Overview
This notebook addresses the tasks of web scraping, data wrangling, and data exploration. It includes:

- **Web Scraping**: Extracting data from a Wikipedia page using BeautifulSoup and Requests.
- **Data Wrangling**: Matching the extracted data with the Iris dataset from Seaborn.
- **Data Exploration**: Performing statistical analysis and visualizations on the Iris dataset.

### Tasks Covered:
1. **Web Scraping**:
   - Scraped the Iris dataset from a Wikipedia page and converted it into a DataFrame.
   
2. **Data Wrangling**:
   - Renamed columns, matched data types, and ensured the structure matched the Seaborn Iris dataset.

3. **Data Exploration**:
   - Calculated summary statistics (mean, standard deviation, etc.) for the Iris dataset.
   - Created scatter plots and a correlation matrix to analyze the relationships between features.
